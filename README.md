# Запросы аудита — номер последней версии

Здесь только файл `version.json`: номер последней версии программы «Запросы аудита», дата, «Что нового» и где взять новую версию.
Программа читает этот файл при запуске (проверку можно отключить в настройках) и ничего не отправляет о пользователе.

Кода программы, сборок и данных в этом репозитории нет.
